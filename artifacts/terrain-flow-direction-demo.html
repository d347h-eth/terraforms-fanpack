Terrain resource-flow phase: floor(time + height + 0.5 * col + 0.1 * DIRECTION * row) % 9

Solidity changes DIRECTION once per day over a 10-day palindromic cycle: 5, 4, 3, 2, 1, 0, 1, 2, 3, 4. The browser loop moves the phase continuously; DIRECTION only changes the row gradient, so the apparent angle opens and closes instead of rotating around a center. This demo fixes height to zero to isolate that directional term.

Left to right: minimum row-gradient, middle row-gradient, maximum row-gradient, then the animated daily cycle. The animated panel uses the same field shape and accelerates time so the 10-day cadence can be inspected.
